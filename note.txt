3. Hỏi về việc deploy trên GitHub Pages có đúng với yêu cầu "có hosting" không
Bạn hỏi: Đẩy web lên GitHub Pages có đúng không? Thầy yêu cầu phải có hosting

→ Tôi trả lời:

GitHub Pages là một dạng hosting tĩnh (static hosting) nên:

Nếu chỉ cần web chạy được: OK

Nếu cần xử lý CSDL: Không đủ (vì GitHub Pages không hỗ trợ backend)

→ Giải pháp:

Vẫn deploy frontend ở GitHub Pages

Deploy backend (API + DB) ở nơi khác như Render, Railway, hoặc dùng localhost khi demo
